# Resmi başvuru kaynakları / Official references

Kurulum ve sürüm kararlarında 2 Kasım 2026 tarihinde resmi paket kayıtları ve birincil belgeler kontrol edildi.

- [Node.js sürümleri](https://github.com/nodejs/node/releases) — yerel test Node 24.22.1 LTS.
- [discord.js v14 belgeleri](https://discord.js.org/docs/packages/discord.js/14) — kullanılan paket 14.28.0; gerçek tip tanımları derleme sırasında doğrulandı.
- [Discord Developer belgeleri](https://discord.com/developers/docs/intro) — bot uygulaması, intent, yetki ve etkileşim kuralları.
- [Drizzle SQLite](https://orm.drizzle.team/docs/get-started-sqlite) — yerel SQLite sürücüsü.
- [GitHub checkout](https://github.com/actions/checkout) · [Node kurulumu](https://github.com/actions/setup-node) · [pnpm kurulumu](https://github.com/pnpm/action-setup) — CI tanımlarının resmi kullanım belgeleri. Uzak workflow çalıştırılmadı.

Paketlerin tam sürümleri package.json ve pnpm-lock.yaml içinde sabitlenir. Belgeler gelecekte değişebilir; bu teslimatın çalıştırılmış kontrolleri PROJECT_STATUS.md içinde kaydedilir.
