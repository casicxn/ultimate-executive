# Güvenlik / Security

Güvenlik açıklarını herkese açık issue içinde istismar ayrıntılarıyla paylaşmayın. Depo sahibi GitHub private vulnerability reporting özelliğini etkinleştirdiğinde bu kanalı kullanın. Henüz yayınlanmamış bu teslimatta iletişim adresi tanımlı değildir; adres uydurulmamıştır.

Token `.env` dosyasında tutulur; sızarsa Discord Developer Portal üzerinden yenileyin. SQLite dosyasını ve yedeklerini yalnız bot işletmecisinin erişebileceği konumda saklayın. Veritabanı şifrelenmez.

Yetki atamaları sunucu sahibi veya açıkça atanmış yapılandırma yöneticisine aittir. Discord Administrator yetkisi personele zorunlu değildir. Botun rolü yönetilecek rollerin üzerinde olmalıdır; personele bot üzerinden hiyerarşi atlama hakkı verilmez.

Report vulnerabilities privately through the repository's private reporting channel when configured. No contact address has been invented for this unpublished project. Rotate leaked Discord tokens, restrict database and backup access, and use a controlled test guild. The local database is not encrypted.
